## Evidence boundary

The showcase records an approved real migration using Overture Matte PLA and Overture PLA Pro. It proves local creation, Bambu Studio loading, and unique cloud IDs. AMS verification remains pending and operator-only.

The V2 promo uses the approved Overture app footage with a darker grade so the light interface remains readable. Its GPT Image 2 explainer shows selected profile tiles moving together into a larger organized list. It is a concept illustration, not a Bambu Studio screenshot or a claim of automatic AMS setup.

The V1 promo also uses redistribution-safe synthetic Fiberlogy plan imagery to explain conflict review. Local creation, Bambu loading, cloud ID assignment, and AMS verification are never presented as the same state.
