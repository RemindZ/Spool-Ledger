# v0.9.0 preparation record

Recorded 2026-09-12 on `release/v0.9.0`, before integration and artifact builds. This is a preparation snapshot, not a publication claim.

## Approved scope

The owner requested the first public beta and explicitly approved making the repository public, integrating the reviewed changes through protected main, creating and pushing v0.9.0, and publishing verified unsigned artifacts. Existing disclosed campaign media was approved for public inclusion. Media entitlement is owner-confirmed, not independently audited.

Windows x64 is the beta-supported platform. The owner authorized macOS as an alpha preview needing additional testing and feedback because exact human-tested environment and artifact records are unavailable. The matrix retains `release_enabled: false` and pending Mac evidence. Its exception permits only v0.9.0 with explicit prerelease mode, not stable distribution or a later version.

- Updated application versions and root lockfile entries to 0.9.0.
- Added beta feature notes and explicit prerelease flags while preserving draft-only automation and manual publication.
- Added focused negative tests for the Mac alpha exception.

- Corrected tracked marketing provenance and replaced absolute production manifest paths with repository-relative paths.

- Exact v0.9.0 prerelease contract: passed with four expected artifacts. Regression tests reject stable mode, later tags, Windows alpha exceptions, and missing evidence.

## Artifact and publication gates

No prior 0.1.0 artifact is relabeled as 0.9.0. New artifacts must come from the accepted protected tag, pass independent checksum and provenance verification, and receive feasible installation/version/read-only discovery checks. Mac human acceptance remains incomplete and must stay explicit in the published notes.

The GitHub release, once published, is the authority for final asset identities, source commit, checksums, and publication status. This preparation record does not assert that integration, tagging, artifact verification, or publication has already happened.
