# Spool Ledger v0.9.0 beta release notes

Spool Ledger, the Bambu Filament Migrator, is an independent local-first desktop utility for bringing compatible OrcaSlicer and Bambu Studio filament presets into Bambu Studio custom profiles.

## First public beta

- Select factory or custom source presets and installed official Bambu printers and nozzles.
- Review a frozen migration plan before creating local profiles.
- Back up affected files and retain transaction journals and receipts.
- Track local creation, Bambu loading, cloud ID assignment, and operator AMS verification separately.
- Restore only transaction-owned files whose current hashes still match the recorded run.

## Compatibility and limitations

Windows x64 is the beta-supported platform, with NSIS, MSI and portable packages. **macOS alpha preview: additional testing is needed, and we welcome your feedback.** The universal DMG includes Apple Silicon and Intel slices, but exact human acceptance records remain incomplete. Linux and custom printers are not supported in this beta.

A locally created profile does not establish that Bambu Studio has loaded it, assigned a cloud ID, or exposed it in the AMS. Continue through normal Bambu Studio loading and synchronization, and verify AMS visibility yourself.

## Installation and trust

The Windows packages are unsigned. The macOS application is unsigned and not notarized. Operating-system security warnings are expected; verify the release source and published SHA-256 checksums before approving installation. Do not disable operating-system security globally.

This is a beta. Keep independent backups and review each plan before proceeding. Do not run a migration while Bambu Studio remains open.

Spool Ledger is not affiliated with or endorsed by Bambu Lab or OrcaSlicer. Source licensing is AGPL-3.0-only.
