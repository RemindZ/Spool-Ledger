Build output names

Click a name box to make it active, then combine reusable blocks with your own text.

Compose a name

  • Click a name box and type custom words, punctuation, or spacing between its blocks.
  • Click a building block to add it to the active name, or drag it into position.
  • Drag existing blocks to reorder them. Remove a block with ×, Delete, or Backspace.
  • The preview shows the resulting name before a migration plan is built.

Blocks and outputs

  • Vendor, family, material, and variant can be used in either name.
  • Printer, nozzle, and the @ separator apply only to slicing presets.
  • The Create output switch beside each name controls whether that output is generated. At least one output remains enabled.

Advanced naming rules

Rules handle predictable source-name exceptions after you have defined the normal template.

How a rule works

  • Output chooses whether the rule applies to slicing presets or AMS identities.
  • Rule kind uses a wildcard for simple matches or a regular expression for precise patterns.
  • Pattern finds the source fragment; Replacement supplies the normalized wording.
  • Source condition limits the rule to a material, vendor, or source application.
  • Rules run in the displayed order. Use Move up and Move down when one rule must take precedence.
Pattern: *-HS
Replacement: * High Speed
Condition: Material is PETG

Use these rules only for repeatable exceptions. Put ordinary words and separators directly in the name boxes above.
